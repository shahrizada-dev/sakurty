# Saryagash Retreat

Локальный статический сайт на казахском, русском и английском языках. Для работы нужны только HTML, CSS и JavaScript. Сайт не использует базу данных, аналитику, трекеры и внешние шрифты.

## Запуск

Откройте `index.html` в браузере или запустите папку через расширение Live Server в VS Code.

## Настройка

- Данные поездки, WhatsApp, телефон и социальные сети меняются в `config.js`.
- Переводы находятся в `translations.js`.
- Основная разметка находится в `index.html`.
- Стили и анимации находятся в `style.css`.
- Фотографии находятся в `assets/`.

Все личные поля в `config.js` оставлены пустыми. После заполнения формы посетитель сам нажимает кнопку отправки в WhatsApp.

## GitHub Pages

Загрузите содержимое этой папки в корень репозитория и включите GitHub Pages для ветки `main`, папки `/root`. Сборка не требуется.
